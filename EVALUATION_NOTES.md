# Round 1 checklist

- Train from scratch and record the dataset source/license.
- Show held-out accuracy, precision, recall, F1, ROC-AUC and confusion matrix.
- Demonstrate one local SHAP explanation and describe it as model behaviour, not causality.
- Show fairness group sizes, approval rates and error rates only for attributes actually present.
- Do not claim the model is unbiased or production-ready.
- Verify a fresh clone can install requirements, train, and launch.
- Prepare a five-minute demo and backup screenshots.
